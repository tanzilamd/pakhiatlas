# One useful home for each care procedure

Keep profiles specific to the bird. Shared instructions belong in a guide; profiles can explain species-specific differences and link readers to the procedure through `relatedGuides` frontmatter. Do not copy an entire care checklist into every profile or rewrite it slightly just to evade duplicate detection.

| Topic | Canonical guide slug |
| --- | --- |
| Whole-diet principles and dietary groups | balanced-diet |
| Cockatiel meal/ingredient choices | cockatiel-feeding |
| Dry seed quantities, planning and storage | seed-mix |
| Safe gradual diet transitions | food-transition |
| Droppings components, changes and urgent signs | droppings |
| Cage cleaning and cleanup workload | cleaning-and-droppings |
| Illness assessment and urgent veterinary transport | illness-emergency / travel-care |
| Shared wildlife observation/identification context | wild-bird-observation |

Other existing guide slugs own housing, first-week care, training, quarantine and breeding. Read the actual article before adding another guide on the same subject. A short contextual safety cue, related-reading title, navigation label or source ID may appropriately recur. Different species' actual differences must not be erased merely because a topic is shared.

This revision audited normalized paragraphs longer than180 characters across both languages, excluding headings, HTML and pure link blocks.501 repeated paragraph copies across86 localized profiles were consolidated, while216 resulting link-only headings became validated relatedGuides entries. Origin text retained species-specific locations. Shared wildlife guidance moved into one new paired guide. Profiles retain their own biology, appearance, temperament and species-specific care information; this is not a target word-count reduction.

`scripts/content-duplicates.mjs` rejects exact repeated long prose blocks (including within one article), reports locations and runs through content validation/build. It does not prove originality, identify every semantic paraphrase or replace editorial judgment. `npm run validate:duplicates` runs it directly. Keep essential information equivalent across English/Bangla while writing natural Bangla; translations are not duplicate articles to delete.
